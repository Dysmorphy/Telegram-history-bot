# Telegram-history-bot

🚀 Space Race Real-Time Bot
An immersive Telegram bot that plunges users into the atmosphere of the "Space Race" (1955–1975). The bot operates in "real-time," delivering news flashes, launch reports, and archival media on the exact day and month those historical events originally occurred.

📝 About the Project
The goal of this project is to create a sense of presence during the greatest confrontation between superpowers (USSR vs. USA). Users receive notifications about the victories and setbacks of both sides, reading them as if they were breaking news from the past.

Key Features:
Historical Calendar: Daily broadcasts of events occurring on the current calendar day.

Archival Multimedia: Authentic photos and videos attached to key historical milestones.

Dramatic Narrative: Coverage ranging from the construction of Baikonur to the "Apollo-Soyuz" Test Project.

Verified Knowledge Base: Content sourced from reliable archives (NASA History, Roscosmos archives, memoirs of Boris Chertok and Nikolai Kamanin).

🛠 Tech Stack
Language: Python 3.10+

Bot Library: aiogram (Asynchronous framework)

Database: gspread (Google Sheets as a user-friendly CMS) or SQLite.

Task Scheduler: APScheduler for automated daily broadcasts.
